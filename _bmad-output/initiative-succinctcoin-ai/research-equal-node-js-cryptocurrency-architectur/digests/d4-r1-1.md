1. **Lodestar PR #8900 ("feat(blst): use lodestar-z blst") and the `lodestar-z` package** — the stated reason BLS left JS. This is the single most decision-relevant artifact for where a JS equal-node miner's PoW/PoS hot path must live (native N-API vs WASM). Repo: https://github.com/ChainSafe/lodestar/pull/8900.
2. **Nodewatch (ChainSafe's Beacon Chain node tracker, linked from ethereum.org)** — to quantify what fraction of a real production chain actually runs the JS client. Converts "Lodestar exists on mainnet" into "Lodestar carries X% of beacon nodes".

Would add a second, non-Ethereum production TS+libp2p precedent.
4. **bcoin repo pushed_at** (GitHub API once un-rate-limited) + whether any JS PoW implementation documents a mining rate — closes or confirms D4.9/D4.11.
5. **Lodestar Grafana dashboards + `docs/pages/faqs.md` heap/GC notes** (repo `dashboards/` dir, incl. "track EL engine request/response bytes") — real 24/7 operational evidence of GC/heap behavior in a long-lived Node process.
