- (capability) CAP-1 slot-based mining: every running node's probability of winning a slot is proportional to its uptime alone - independent of CPU/GPU hashrate and of stake - with slot target set so commodity hardware reaches it trivially (sha256 ~3GB/s measured)
- (capability) CAP-2 operator identity: an operator acquires exactly one base identity via a pluggable personhood gate; acquiring a second identity for the same operator costs at least as much as the first without scaling the mining reward (registration composition per registration-design.md)
